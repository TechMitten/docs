Connect LMSA to LM Studio running on your computer for fully local, private chat. All traffic stays on your network.

<Steps>
  <Step title="Start the LM Studio server">
    Open LM Studio on your host computer and start the server. Enable **Serve on local network** so LMSA can reach it.
  </Step>
  <Step title="Find the host IP address">
    Check your computer's Wi-Fi adapter IP:

    - **Windows:** Open Command Prompt, type `ipconfig`, and look for the IPv4 Address under "Wireless LAN adapter Wi-Fi"
    - **macOS:** Go to System Preferences > Network, select Wi-Fi, and note the IP address
    - **Linux:** Open Terminal and type `ifconfig` or `ip a`
  </Step>
  <Step title="Enter the connection address in LMSA">
    Open LMSA **Settings** and enter the host IP address plus the LM Studio server port. The default port is **1234**, or whatever LM Studio shows.

    Example: `http://192.168.1.25:1234`
  </Step>
  <Step title="Load a model">
    Use the **Models** button in LMSA to load and switch models. Do not load models directly in LM Studio while using LMSA.
  </Step>
  <Step title="Start chatting">
    Tap **Apply**, return to the chat, and send your first message.
  </Step>
</Steps>

<Warning>
  The connection between your Android device and the LM Studio server is not encrypted. Only use LMSA on networks and devices you trust. Avoid sending passwords or sensitive personal information.
</Warning>

<Info>
  If you have trouble connecting, see the [connection troubleshooting guide](/troubleshooting/connection-issues).
</Info>

OpenRouter is a cloud gateway that gives you access to over 100 AI models from providers like OpenAI, Anthropic, Google, Meta, and others — all through a single API key. LMSA connects directly to OpenRouter's API using your key, with no intermediate servers involved.

<Warning>
  Using OpenRouter sends your messages to OpenRouter's cloud API, which then forwards them to the selected model provider. Your conversations are not processed locally. If privacy is your priority, use a local provider such as [LM Studio](/providers/lm-studio) or [Ollama](/providers/ollama) instead.
</Warning>

## Get an OpenRouter API key

<Steps>
  <Step title="Create an OpenRouter account">
    Go to [openrouter.ai](https://openrouter.ai) and sign up for a free account.
  </Step>
  <Step title="Generate an API key">
    In the OpenRouter dashboard, navigate to **Keys** and create a new API key. Copy the key — you will only see it once.
  </Step>
</Steps>

## Connect LMSA to OpenRouter

<Steps>
  <Step title="Open Settings in LMSA">
    Tap the settings icon in the top-right corner of the LMSA home screen.
  </Step>
  <Step title="Select OpenRouter">
    On the **Connection** step, tap **OpenRouter**.
  </Step>
  <Step title="Enter your API key">
    Tap **Configure** and paste your OpenRouter API key. Tap **Save**.
  </Step>
  <Step title="Choose a model">
    LMSA will load the full list of available OpenRouter models. Tap the model picker and select the model you want to use.
  </Step>
  <Step title="Start chatting">
    Send your first message. Responses are generated by the cloud model you selected and returned directly to LMSA.
  </Step>
</Steps>

## Free and paid models

OpenRouter offers a selection of free models that you can use without adding credits to your account. Paid models are billed directly on the OpenRouter side — LMSA does not handle any payments or subscriptions. Check [openrouter.ai/models](https://openrouter.ai/models) for the current pricing of each model.

<Note>
  The Smart Reply feature is not available when OpenRouter is selected as your connection type.
</Note>

## Privacy details

When you use OpenRouter, your chat messages travel from LMSA directly to OpenRouter's API — no LMSA servers are involved. OpenRouter then routes your request to the underlying model provider (such as OpenAI or Anthropic) according to their own privacy and data retention policies. Review [OpenRouter's privacy policy](https://openrouter.ai/privacy) for details on how they handle your data.

## Troubleshooting

<AccordionGroup>
  <Accordion title="No models load after entering my API key">
    Check that your API key is correct and has not been revoked. You can verify it in the OpenRouter dashboard under **Keys**. Also confirm that your Android device has an active internet connection.
  </Accordion>
  <Accordion title="I get an error when sending a message">
    Some models require credits on your OpenRouter account before you can use them. Log in to OpenRouter and check your credit balance. Free models do not require credits.
  </Accordion>
  <Accordion title="Responses are slower than expected">
    Response speed for cloud models depends on the provider's infrastructure and the size of the selected model. Smaller models (for example, 7B or 8B parameter models) generally respond faster.
  </Accordion>
</AccordionGroup>

<Tip>
  Use **Saved Presets** in LMSA's Connection settings to save your OpenRouter configuration. This is especially helpful if you switch between OpenRouter and a local provider.
</Tip>

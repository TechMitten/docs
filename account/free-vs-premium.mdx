Chat usage is unlimited on both the Free and Premium tiers. Current limits mainly apply to web search and which advanced features are enabled.

## Comparison

| Feature | Free | Premium |
| --- | --- | --- |
| Chats | Unlimited | Unlimited |
| Ads | Yes | No |
| AI Image Generation | Not available | Unlimited |
| Max Output Tokens in App | Adjust in **Settings > Options** | Adjust in **Settings > Options** |
| Context Length | Adjust in **Settings** | Adjust in **Settings** |
| File Attachments | Attach files to chats | Attach files to chats |
| TTS (Text-to-Speech) | Unlimited, full voice access | Unlimited, full voice access |
| Voice Mode | Not available | Unlimited |
| Custom Templates and v2 Character Cards | Create, import, and use | Create, save, edit, and reuse |
| Web Search | Not available | Unlimited |
| Offline Use (Local LM Studio/Ollama) | Not listed | Full access |
| OpenRouter Access | Not listed | Full access |
| One-Time Purchase | Not applicable | Lifetime upgrade |

<Note>
  **Voice Mode**, **Web Search**, and **AI Image Generation** are Premium-only features.
</Note>

## How to upgrade

<Steps>
  <Step title="Open Premium Settings">
    Tap the **Support Indie Dev** button in the Premium Settings menu.
  </Step>
  <Step title="Complete purchase">
    Complete a one-time lifetime purchase.
  </Step>
  <Step title="Access premium features">
    Access premium-only features like offline access, web search, and Voice Mode.
  </Step>
</Steps>

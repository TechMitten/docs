LMSA (Local Model Smart Assistant) is a premium Android app that gives you a full-featured AI chat interface — without subscriptions, without sending your data to third-party servers, and without sacrificing capability. You connect it to an AI provider of your choice: a local server running on your own PC, or a cloud API you control, and LMSA handles the rest.

## How LMSA connects to AI

LMSA supports three types of AI providers. You choose one in the app's settings.

<CardGroup cols={2}>
  <Card title="LM Studio" icon="server">
    Connect to a GGUF model running locally on your PC or Mac via LM Studio. Your conversations never leave your home network.
  </Card>
  <Card title="Ollama" icon="server">

  </Card>
  <Card title="OpenRouter" icon="cloud">

  </Card>
  <Card title="Custom endpoint" icon="plug">
    Point LMSA at any OpenAI-compatible API endpoint with an optional API key. Works with self-hosted or enterprise deployments.
  </Card>
</CardGroup>

## Key benefits

**Privacy first.** When you use a local provider, your conversations stay entirely on your device and local network. LMSA collects no telemetry and tracks no conversations. When using OpenRouter, your requests go directly to the provider — there are no middleman servers.

**No subscriptions.** Download LMSA for free and use the core features immediately. Upgrade once with a one-time in-app purchase to remove ads and unlock all premium capabilities — including Character Card generation and unlimited image generation — forever.

**Any model, any time.** Switch between a locally loaded GGUF model on your PC and 100+ cloud models without leaving the app. LMSA makes model-switching instant.

**Built for mobile.** LMSA renders LaTeX math, highlights code syntax, plays AI responses aloud with Text-to-Speech, supports biometric lock, and scales across phones and tablets.

## System requirements

| Requirement | Details |
|---|---|
| Android version | 6.0 (Marshmallow) or higher |
| Local server mode | Your phone and PC must be on the **same Wi-Fi network** |
| Cloud mode | Active internet connection; OpenRouter API key required |
| Storage | Varies by usage — conversations are stored on-device |

<Note>
LMSA does not run AI models on your phone. It acts as a lightweight interface that connects to a model running on your PC (local mode) or a cloud API (cloud mode). Your phone's processing power does not affect model performance.
</Note>

## What you can do with LMSA

- Chat with any LLM using custom system prompts and persona templates, including full Character Card V2 support
- Attach images, PDFs, and documents for context-aware analysis
- Generate images directly in chat with the `/image` command
- Search the web in real time with Brave Search integration
- Listen to AI responses with native Text-to-Speech
- Secure your chat history with biometric (fingerprint or face) unlock
- Save and switch between multiple server connection presets
- Export chat histories for backup or analysis

You can back up and restore your conversations using the Export and Import features in the sidebar menu.

## Export chats

Use **Export Chats** to save all your conversations to a file. Store exported files securely to protect your privacy.

## Import chats

Use **Import Chats** to restore previously exported conversations. You can choose to merge imported chats with existing ones or replace them entirely.

<Warning>
  **Security warning**: Exported chat files are stored as unencrypted JSON files. Anyone with access to your device or the exported file can read your conversations in plain text, even without using LMSA.
</Warning>

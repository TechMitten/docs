title: "Customize fonts, scrollbars, and chat behavior in LMSA"
description: "Change fonts, font sizes, scrollbar visibility, auto-scroll behavior, enter key behavior, and other display options to personalize the LMSA experience."
---

LMSA's interface is built to get out of your way — but a handful of display and behavior options let you tune the experience to match how you actually use the app. Most of these settings live in **Settings → Options (Step 2)** under the **Chat Interface** group, with font controls on **Step 4 (Font)**.

## Chat font

### Font family

Change the typeface used in all message bubbles — both your messages and the AI's responses.

Navigate to **Settings → Step 4 (Font) → Chat Bubble Font** and choose from the dropdown:

| Option | Font |
|---|---|
| System Default | `system-ui, sans-serif` |
| Roboto | `Roboto, sans-serif` |
| Sans-Serif | `Arial, Helvetica, sans-serif` |
| Serif | `Georgia, serif` |
| Monospace | `Courier New, monospace` |

### Font size

Adjust the text size in message bubbles. Navigate to **Settings → Step 4 (Font) → Chat Bubble Font Size**:

| Option | Size |
|---|---|
| Extra Small | 12 px |
| Small | 14 px |
| **Medium (Default)** | **16 px** |
| Large | 20 px |
| Extra Large | 24 px |

<Tip>
If you use LMSA on a large tablet or an e-ink device, bumping the font size to Large or Extra Large significantly improves readability.
</Tip>

## Display toggles

All of the following options are in **Settings → Options → Chat Interface**. Tap any card to toggle the feature on or off.

### Model Name label

When **Model Name** is on, a small badge appears on each AI response showing which model generated it. This is useful when you switch models mid-conversation or want to track which model produced a specific answer. On by default.

### Chat Scrollbar

When **Chat Scrollbar** is on, a visible scrollbar appears along the right edge of the chat window. Off by default.

### Scroll-to-Bottom button

A floating button that jumps the chat view to the latest message. Enabled by default — toggle it off if you prefer a cleaner interface.

<Note>
The scroll-to-bottom button appears automatically when you scroll up through older messages and disappears when you are already at the bottom of the conversation.
</Note>

### Auto Scroll

When **Auto Scroll** is on, the chat view follows the AI's output as it streams in — keeping the newest text visible without you having to manually scroll. Off by default.

## Behavior toggles

### Enter New Line

Controls what happens when you press Enter in the message input field.

| Setting | Enter key | Send key |
|---|---|---|
| **Off (default)** | Sends the message | — |
| **On** | Inserts a new line | Shift + Enter sends |

Enable **Enter New Line** in **Settings → Options → Chat Interface → Enter New Line** if you frequently compose multi-paragraph messages.

## AI response options

### Chat Titles (Auto-Generate)

When enabled, LMSA asks the model to generate a short title for your conversation after the first exchange. The title appears in the chat history list. Off by default.

Find this in **Settings → Options → Smart Features → Chat Titles**.

### Hide Thinking

For reasoning models that expose their chain-of-thought (such as DeepSeek-R1), the **Hide Thinking** toggle controls whether the reasoning block is shown in the chat. When hidden, the model still reasons internally — you only see the final answer.

Find this in **Settings → Options → AI Settings → Hide Thinking**.
